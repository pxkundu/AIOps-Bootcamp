# Resources: Glean for Enterprise AIOps & Security

Explore the tools, frameworks, and theoretical foundations of Modern Enterprise Knowledge Discovery and security automation.

---

## 🔍 Glean Platform Resources

- **Glean Official Documentation**: [Glean.com](https://www.glean.com/) - Overview of the platform and product capabilities.
- **Glean Developer Portal**: [Glean API & SDK](https://developers.glean.com/) - Integrating custom apps and data sources.
- **Case Studies**: [How Enterprises use Glean](https://www.glean.com/customers) - Real-world deployment examples.

---

## 🛡️ Enterprise Data Security & Analytics

- **OWASP API Security Project**: [Top 10 API Security Risks](https://owasp.org/www-project-api-security/) - Critical for building secure analytics pipelines.
- **Data Privacy & Protection**: [GDPR Compliance for Data Pipelines](https://gdpr.eu/data-protection-compliance-checklist/) - Thinking about PII at scale.
- **Secrets Management**: [HashiCorp Vault](https://www.vaultproject.io/) - The gold standard for Managing Enterprise Secrets.
- **Identity & Access Management (IAM)**: [NIST IAM Guide](https://www.nist.gov/identity-management) - Foundational knowledge for Glean permission mapping.

---

## 🛠️ AIOps Integration & LLMs

- **LangChain for Enterprise**: [Enterprise RAG Patterns](https://python.langchain.com/docs/use_cases/question_answering/) - How to build the "AI Assistant" layer.
- **Vector Databases for SREs**: [Pinecone Blog on Semantic Search](https://www.pinecone.io/learn/vector-database/) - Understanding the "under-the-hood" similarity search.
- **Causal Inference at Scale**: [Microsoft's DoWhy Library](https://microsoft.github.io/dowhy/) - Using Glean's data lineage for RCA.

---

## 📚 General Knowledge & Best Practices

- **Google SRE Book**: [Embracing Risk](https://sre.google/sre-book/embracing-risk/) - Calculating the risk of security automation.
- **Martin Fowler**: [Data Mesh Architecture](https://martinfowler.com/articles/data-mesh-principles.html) - Understanding the federated data structures Glean organizes.
- **Security as Code**: [Infrastructure as Code (IaC) Patterns](https://www.terraform.io/) - How Glean-SEC can monitor configuration drift.
