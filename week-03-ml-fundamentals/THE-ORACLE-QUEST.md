## 🎯 Pre-Week Challenge: "The Ghost in the Metrics"

Before you start Day 1, you must solve this puzzle.

**The Scenario:**
A server emitting latency metrics is behaving strangely. Most requests take 50ms, but every few minutes, a group of requests takes exactly 500ms.

**The Task:**
1. Is this a **Normal Distribution**?
2. If you were to plot a histogram of this, how many **Peaks (Modes)** would you see?
3. **Bonus:** What is the technical term for a distribution with two peaks?
